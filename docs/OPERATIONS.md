# راهنمای کار روزمرهٔ «گفتگوهای خاموش»

این سند کوتاه و دوستانه است؛ هر چی لازمه که پروژه هفته‌به‌هفته بچرخه همین‌جاست.

## ۱. ایده در یک نگاه
**داستان تصویری (اینستاگرام) ← آزمون ۲ دقیقه‌ای (`/quiz/`) ← فهرست ایمیل/موبایل ← دوره و کارگاه.**
پست‌ها آدم‌ها رو کنجکاو می‌کنن، آزمون سطحشون رو نشون می‌ده و فرم آخر آزمون «لید» رو می‌گیره. کتاب فقط یک پلهٔ بعدی توی «مسیر یادگیری»ه، نه هدف اول.

## ۲. نصب سایت (فقط یک‌بار)
1. در وردپرس: نمایش ← افزودن پوسته ← بارگذاری `silent-talk-theme.zip` ← فعال‌سازی.
2. تنظیمات ← پیوندهای یکتا ← «نام نوشته» را انتخاب و ذخیره کن (برای آدرس `/quiz/`). اگه خاموش بمونه، لینک‌ها خودکار به `/?st_quiz=1` برمی‌گردن و باز هم کار می‌کنن.
3. نمایش ← سفارشی‌سازی ← «Silent Talk»: لینک اینستاگرام (`https://instagram.com/silenttalk.ir`)، لینک طاقچه و راه تماس را پر کن.
4. تنظیمات ← خواندن: صفحهٔ اصلی «آخرین نوشته‌ها» بماند؛ قالب خودش صفحهٔ اصلی را می‌سازد.
5. یک‌بار خودت آزمون را بزن و فرم آخرش را پر کن؛ باید در منوی «لیدها» ببینی.

## ۳. لینک‌گذاری (UTM) تا بفهمیم هر پست چقدر جواب داد
لینک بیو و استوری‌ها:
`https://silenttalk.ir/quiz/?utm_source=instagram&utm_medium=carousel&utm_campaign=p01&utm_content=bio`
- `utm_campaign` = شمارهٔ پست (p01, p02, …)
- `utm_content` = `bio` / `story` / `dm`
لینکدین: `utm_source=linkedin&utm_medium=post`
دکمهٔ «برای یه دوست بفرست» خودش `utm_source=share` اضافه می‌کنه.

## ۴. هر هفته چه کار کنیم (۳۰ دقیقه)
1. **دوشنبه:** سه داستان هفته (متن + تصویر + کپشن) آماده می‌شه و برای تأیید می‌آد.
2. **تو:** یک بار می‌بینی و تأیید/اصلاح می‌کنی. بدون تأیید هیچ چیزی منتشر نمی‌شه.
3. **انتشار:** آپلود دستی در اینستاگرام (روش رسمی API هنوز تأیید نشده) و پست مدیریتی لینکدین.
4. **جمعه:** آمار را نگاه می‌کنیم و پست هفتهٔ بعد را بر اساسش می‌نویسیم.

## ۵. آمار
- لیدها: وردپرس ← لیدها (ستون «آزمون» سطح و امتیاز را نشان می‌دهد). خروجی CSV از همان‌جاست.
- آمار JSON (برای ادمین): `/wp-json/silent-talk/v1/stats` شامل `by_source`, `by_campaign`, `by_quiz_level` و `quiz_funnel` (شروع ← پایان ← سطح‌ها).
- شاخص‌های مهم: نرخ شروع به پایان آزمون، نرخ ثبت فرم بعد از نتیجه، و کدام کمپین بیشترین لید را آورد.

## ۶. تصویرسازی
- شخصیت‌ها (۳بعدی، سبک انیمیشنی) را در همان چت ChatGPT «پرامپت‌های ساخت تصویر» می‌سازیم تا ظاهرشان ثابت بماند.
- پرامپت‌ها در `dist/gpt-prompts.md`، کاراکتر ثابتِ میزبان: خانم با کت زرشکی و عینک؛ آقای «کیانی» با موی خاکستری و ریش.
- ساخت اسلایدها: `render/build_photo.py` (متن فارسی روی تصویر؛ خروجی ۱۰۸۰×۱۳۵۰).

## ۷. حریم خصوصی و محدودیت‌ها
- فقط اسم و راه تماس با رضایت صریح گرفته می‌شه؛ آمار قیف کاملاً ناشناسه.
- ضدّ ربات: honeypot، حداقل زمان پر کردن، محدودیت تعداد، و جلوگیری از ثبت تکراری.
- ما هیچ ربات لایک/کامنت/فالو نداریم و نمی‌سازیم.
- رمز و تنظیمات امنیتی حساب‌ها دست ماست نه Claude؛ انتشار فقط با تأیید تو.

## ۸. بعدی‌ها
داستان ۲ و ۳، پروفایل اینستاگرام (آواتار میزبان + بیو + لینک آزمون)، پست‌های لینکدین، و بعد دورهٔ تعاملی.
